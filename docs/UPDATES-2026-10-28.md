# October 28 update

This public release includes the reusable source changes from the current private deployment. It contains no live configuration, member database, credentials, private reports, or deployment-specific role/channel mappings.

- Queue opening waitlist-role mentions persist until the regional queue closes, with restart recovery and protection against stale notifications.
- Discord account usernames in ticket names, linked creation confirmations, /maketestticket, /requestclose, and support /forceclose.
- Dedicated optional CD Resetter permission group, isolated from other Bot Admin operations.
- Configurable opening notification roles; four published high lists (HT3 through LT1), departed-member pruning, and saved-tier restoration after restrictions.
- Faster archive scheduling, bulk channel locking, multipart transcripts, separate result delivery, and safe recovery after failed Discord requests.
- Remote document compression, revision polling, batched CAS changes, small lease rows, bounded requests, and restart on lease failure.
- Stopped-service local SQLite transfer utility with validated recovery exports.

The guide, compiled distribution, package manifest and full-package ZIP are rebuilt with these changes. Rehearse permissions, mention delivery, archives and database recovery on your own server before rollout. Automated tests do not replace those live checks. Daily local backups require a running bot and an independent off-host copy for disk-loss protection.
