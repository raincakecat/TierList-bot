CRYSTAL BOT COMMANDS - 0.2.0

Owner inherits the bot's configured permission groups. Ticket tools still require access to the ticket. Support closure uses the responsible type's closing groups and its Close button.

MEMBERS
/profile [member] - Saved player profile.
/leave - Leave queue.
Verify Account / Enter Waitlist / Join Queue / support type menu - Player buttons and menus.

VERIFIED TESTER (also needs Staff for testing work)
/start region - Start regional testing session.
/stop - Stop session.
/next - Open next eligible FIFO test.

STAFF
/loa status [member] - Private current/latest leave status; your own pending/active record includes withdraw/end controls.
/passeval - Pass evaluation; continue HT3 test.
/skip - Skip before evaluation passes.
/close tier - Finish test or discontinue.
/format tier - Fight-result Markdown template.
/add member /remove member - Manage added participants.
/rename name - Rename current ticket.
/forceclose reason - Immediately close the current support ticket without opener approval. Responsible closing staff or Owner only; required reason; transcript archival still precedes deletion. Testing tickets use /close instead.
/ticketclose reason - Alias for /forceclose with the same support-only closing permissions and transcript protection.
/requestclose reason timeout - Responsible closing staff (Staff for testing) or Owner can request closure for 1h-7d. Only the opener approves or denies. Approval or unanswered expiry closes through archival; denial keeps it open. Testing closure discontinues without test credit.
/addht3 /addlt2 - Select eligible regional opponent.
/set-ticket type member [tester] - Adopt existing channel.
/maketestticket member tester - Register the current channel as a testing ticket. Staff with channel access; tester must be a Verified Tester.
/changeticket type [tester] - Change permitted ticket route.
/uuid ign - UUID lookup.
/stats [member] /testerstats - Monthly statistics.
/testerlb [period] - Monthly, weekly, or all-time leaderboard.
/ht3list list /lt2list list /ht2list list /lt1list list - View members.

CD RESETTER
/resetcooldown member - Clear one player's cooldown. No other Bot Admin permissions.

BOT ADMIN
/health - Private database, jobs, backup, recovery and configuration health; includes state size and safe retry causes.
/unverify member - Unlink Minecraft association; keep Discord rank/cooldown.
/addtester member /stoptester member - Manage tester authorization.
/resetcooldown member - Only if also Owner or CD Resetter.
/configquota count - Monthly quota; 0 disables.
/panels refresh - Refresh configured request panels/lists/queues.
/migration preview filename - Read-only legacy import preview when enabled.
Bot Review controls - Correct supported missing import metadata.

REGULATOR
/deadline set duration /deadline clear - 1m to 14d; notify setter, no automatic close.
/forcestopqueue region - Clear regional sessions/queue.
/forcetest member region - Bypass queue/cooldown; restrictions still enforced.
/forceresult member tier region [ign] - Assign outside active test.
/migrate member tier region source [ign] - Assign migrated rank.

RESTRICTION KEY
/restrict member ign reason [duration] - Restrict account pair, remove list/queue membership.
/unrestrict member - Remove pair restriction, restore the saved pre-restriction tier, and synchronize tier/Restricted roles. Cooldowns stay unchanged; high-list membership is not restored automatically.

LOA ADMIN (Owner inherits)
Accept/Deny buttons in LOA In Progress - Decide a pending request; denial requires a reason.
/loa end member reason - End an approved leave early, with a reason.

LOA REQUESTERS
Request Leave of Absence button - Staff-only form for username, 1d-30d duration, and reason.
Withdraw Request / End My LOA - Requester-only pending cancellation or early return.
One pending/active request per member. Approval starts leave; expiry removes its role. Any approved monthly overlap exempts quota without preventing testing or changing counts.

LIST ADMIN
/ht3list add|remove member region and equivalent lt2/ht2/lt1 commands - Manage regional membership.

OWNER (initial setup allows Discord Administrator before initialization)
/setup wizard - Private draft setup/configuration screens, review and confirmation.
/setup preview /setup apply - Existing resource creation workflow.
/config validate /config reload - Validate settings/Discord resources; reload reviewed file.
/maintenance enabled - Maintenance control.
/backup export /backup restore filename /backup transfer config - Portable recovery.
/migration apply filename /migration retry - One-time import/resume and saved job retry.
/reset member - Reset player, preserving restrictions/archives.
/forceresetcooldowns - Clear all cooldowns.
/forceclosetickets - Discontinue/archive active open tickets.
/setcooldown member days - Set one player's cooldown.
/configcooldown kind duration - Change future test cooldown; 0 disables.

Wizard changes on initialized installations require maintenance. Drafts expire after 15 minutes and confirmations after 5 minutes. Database credentials and initial server ID remain on the host. Backup restore/transfer drain active work with a 30-second waiting limit and keep maintenance enabled.

OWNER BULK OPERATIONS
/purgehightests start reason:<text> — Preview and confirm archival/deletion of high-test channels, including recognized legacy and overflow tickets. Durable asynchronous work; transcripts must upload before deletion. Current ranks/cooldowns stay unchanged.
/purgehightests status — View latest batch progress and retry count. Owner only.
/allcdreset — Confirm and clear every saved cooldown. Owner only; CD Resetter/Bot Admin alone are not sufficient. Existing /forceresetcooldowns remains supported.

MULTI-MODE SERVER NOTES
/start requires mode and region. /next and /stop use your active server session.
Ticket commands infer mode; ambiguous rank/cooldown/list/profile commands require mode outside tickets.
Queue opening: Staff + matching mode Tester role. Ticket handling/assignment: Staff.
/unverify scope:server (default): Bot Admin; only current server.
/unverify scope:global: Owner, confirmation required; shared unlink preserves ranks/cooldowns.
/allcdreset and /forceclosetickets: Owner, all modes in current server only.
/resetcooldown: Owner or CD Resetter; select a mode outside a testing ticket in a multi-mode server.
/setcooldown and /configcooldown: Owner only.
/purgehightests start [mode]: Owner, optional mode narrows current-server purge.
/setup wizard [mode]: Discord Administrator before initialization, Owner afterward.
/activity start: High Staff, Bot Admin, or Owner. Starts a 24-hour staff activity notice and posts a private missing/LOA report when it closes.
/cooldown: Everyone. Privately shows your testing cooldowns in the current server.

CONSOLIDATED MAIN SERVER
Modes: Crystal, Sword, Axe, SMP, Pot, Mace, UHC, Nethpot, Spear Mace.
Queue opening requires Staff + Verified Tester + that mode's Tester role.
Staff may handle assigned test tickets without the selected mode's Tester role.
The three regional queue categories each contain nine mode waitlist channels.
High Testing Lists has one managed forum post per mode; all results use one channel.

SUPPORT SERVER
General Support: Staff can view and close; Staff can view its archive.
Player Reports: Regulator and above handle live tickets; High Staff views the archive.
Staff Reports and Restriction Appeals: High Staff only for live and archive access.
Partnership Requests: Partnership Manager handles live tickets; Partnership Manager and Regulator+ view the archive.
/profile reads the main server's shared player profile when used in Support.
/unrestrict in Support: High Staff or Restriction Key; records the action in both servers.
/migrate member tier region source mode [ign] in Support: Regulator and above. Updates the selected mode in the main server; announcements go to #migrations there. IGN is required for an unverified player.
New support requests use Support's panel. Old open tickets remain in their original server until closed.
/backup export/restore: Owner, all current-server modes; restore rejects cross-server identity conflicts.
/backup transfer: Owner, entire deployment, maintenance required in every server.

REGIONAL QUEUE LAYOUT
Multi-mode setup defaults to NA Queue, EU Queue and AS/AU Queue, each with eight separate mode channels. Queue access remains mode-specific; evaluation tickets open in the shared regional category. High Tests remain separated by mode.
